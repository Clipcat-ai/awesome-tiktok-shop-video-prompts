# Hooks and video formats

Every entry is labelled against two closed vocabularies. They are closed on purpose: free
text labels make a library unsearchable within a few thousand entries.

## Opening hooks

The hook is the first ~2 seconds — the move the video makes before the viewer decides to
stay. `hook` is the primary one; `hooks` lists every hook present.

| Code | Name | The move |
| --- | --- | --- |
| `pain-point` | Pain Point | Names a problem the viewer already has, before naming the product |
| `before-after` | Before & After | Shows the end state next to the start state, immediately |
| `result-first` | Result First | Opens on the outcome, explains later |
| `contrarian` | Contrarian | Contradicts something the viewer believes |
| `benefit-first` | Benefit First | Leads with the payoff as a claim |
| `curiosity` | Curiosity Gap | Withholds the thing the viewer wants to know |
| `identity` | Identity | "If you're the kind of person who…" |
| `pov-scenario` | POV Scenario | Drops the viewer into a situation as a participant |
| `authority` | Social Proof | Numbers, reviews, sold-out, expert |
| `urgency-promo` | Urgency | Price, deadline, scarcity in the first beat |
| `sensory-asmr` | ASMR Sensory | Sound and texture carry the open, no claim |
| `skit-conflict` | Skit Conflict | Two-person setup with a disagreement |
| `weak-generic` | Plain Opener | No real hook — labelled honestly so you can filter it out |

`weak-generic` exists because a video can rank on product-market fit alone. Those entries
are still useful for their shot structure, but do not copy their first two seconds.

## Who is on camera

| Code | Meaning |
| --- | --- |
| `real-person` | One host, face visible |
| `multi-person` | Two or more people |
| `hands-only` | Hands and product only — cheapest to reproduce with AI |
| `no-person` | Product and environment only |

## Promo mechanism

`discount`, `bundle`, `gwp` (free gift), `coupon`, `none`. Labelled from what the video
actually shows on screen or says, not from the product listing.
